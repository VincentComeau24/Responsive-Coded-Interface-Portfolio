# Student Portfolio Landing Page - Vincent Comeau

## Project Description

This project is a single-page student portfolio landing page. It introduces me, highlights my skills, displays selected projects, and provides contact information.

## Intended User or Player

This interface is designed for classmates, instructors, potential employers, and anyone interested in viewing my work.

## User / Player Goal

The user should be able to quickly learn who I am, understand my skills, view examples of my work, and find a way to contact me.

### Inspiration 1 – Black and Yellow Photographer portfolio from Canva
This portfolio inspired the overall layout of my homepage. I liked the large introduction section with a profile image and simple navigation that immediately introduces the person to visitors.

### Inspiration 2 – Alex Williams portfolio website from Weblium
This interface inspired my skills section. I liked how the skills were organized into clean cards that were easy to read, which influenced the layout of my own skills section.

### Inspiration 3 – Adam Smith portfolio website from Weblium
This portfolio inspired my featured projects section. I liked how each project combined an image with a short description, making it easy for visitors to quickly browse the creator's work.

## Design Choices

- Layout: The page uses clear sections and a combination of CSS Grid and Flexbox.
- Color: The design uses white, dark gray, light blue, and blue accent colors.
- Typography: The page uses large headings and readable body text.
- Visual hierarchy: The hero title appears first, followed by skills, projects, and contact information.
- Feedback states: Buttons, links, skills, and project cards change when hovered over or focused.
- Responsive design: Multi-column sections become single-column layouts on smaller screens.
